Verbindungsbeispiele

AWS CLI mit dem Endpoint aus dieser Seite und Path-Style aktivieren:

aws configure set default.s3.addressing_style path
aws --endpoint-url {{ endpoint }} s3 ls s3://{{ bucket }}/
aws --endpoint-url {{ endpoint }} s3 cp ./datei.pdf s3://{{ bucket }}/inbox/datei.pdf

Der Endpoint lässt sich oben aktivieren oder deaktivieren. Für Nicht-Localhost ist HTTPS erforderlich.
