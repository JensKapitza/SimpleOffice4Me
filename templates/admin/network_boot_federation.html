Lokale Boot-Einstellungen

HTTP-Boot ist {{ 'aktiviert' if boot.enabled else 'deaktiviert' }}. Start, Stop, Neustart, Dateisuche und Autostart werden in der Dienstübersicht verwaltet. Stop sperrt öffentliche Bootdateien und beendet auch die zugehörige TFTP-Auslieferung über den Worker.

TFTP verwendet standardmäßig UDP 69 und benötigt auf vielen Systemen passende Dienstrechte. Bind-Adressen müssen lokal vorhanden sein. Fehlstarts werden begrenzt wiederholt und bleiben anschließend als Fehler sichtbar; es wird weder ein Netz geraten noch automatisch mit erhöhten Rechten gestartet.

Erweiterte Einstellungen, Profile und Diagnose

Schalter verwenden true oder false. enabled schaltet die öffentliche Auslieferung frei; tftp_enabled zusätzlich TFTP. tftp_bind ist die lokale IPv4-Adresse; 127.0.0.1 ist nur lokal erreichbar. http_base_url kann für HTTP-Aufrufe leer bleiben; DHCP/PXE benötigt eine für Clients erreichbare Basisadresse. Profile verweisen mit relativen Dateinamen auf vorhandene Bootdateien. default_profile wählt deren ID. Beim Zurücksetzen bleiben Dateien erhalten, die öffentliche Auslieferung wird deaktiviert.

Beispiel: Ein Server kann Networkboot anbieten, ohne fremde Boot-Dateien zu speichern. Ein Backup-Server kann dagegen nur Networkboot-Daten vorhalten, ohne selbst als Boot-Quelle genutzt zu werden. Beide Optionen können auch gleichzeitig aktiv sein.
