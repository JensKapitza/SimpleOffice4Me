# Dokumentationslogo

`simpleoffice-documentation-logo.png` ist die KI-generierte Illustration für
README und Dokumentationsübersicht. Die vorhandene Anwendungsmarke
[`static/icons/simpleoffice.svg`](../../static/icons/simpleoffice.svg) bleibt
der Ausgangspunkt: ein weißer Dokumentordner auf Petrol (`#0f766e`).
Goldene Verbindungen stehen für die Zusammenarbeit vorhandener Fachmodule;
die Umlaufbahn nimmt die kreative Zukunftsvorgabe „2080“ auf.

Das Logo wurde für diese Dokumentationsarbeit neu generiert. Es ist kein
Zertifizierungszeichen und enthält keine Aussage über Release-Freigabe,
Sicherheitsgarantien oder Fehlerfreiheit von KI. Die Anwendungssymbole werden
durch diese Dokumentationsillustration nicht ersetzt.

PNG mit transparentem Hintergrund; in Markdown/HTML mit beschreibendem
Alternativtext und begrenzter Anzeigebreite verwenden. Keine Mailinhalte,
Zugangsdaten, Benutzeridentitäten oder Installationsinformationen enthalten.
