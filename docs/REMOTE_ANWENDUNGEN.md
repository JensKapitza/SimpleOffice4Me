# Remote-Anwendungen vorbereiten

Administratoren finden unter **System → Fernzugriff** (`/admin/remote`) den
Begleitagenten und den Katalog veröffentlichter Anwendungen. Der Agent kann
dort vorbereitet, gestartet und gestoppt werden. Die Seite zeigt die Plattform
und den Zustand des Agenten an.

Um eine Anwendung in den Katalog aufzunehmen, braucht der SimpleOffice-Host
Windows und eine bereits lokal installierte `.exe`-Datei. Unter **Anwendung
freigeben** einen Anzeigenamen, den vollständigen Pfad auf dem Host und die
berechtigten Benutzer auswählen. Ohne Benutzerzuordnung gilt die Freigabe für
Administratoren. Die Freigabe speichert den Fingerabdruck der ausführbaren Datei.
Ein Administrator kann den Katalogeintrag auf derselben Seite entfernen.

Der Katalog ist der aktuelle Bedienpfad. Der Start einer veröffentlichten
Anwendung aus einer Benutzeransicht und die Übertragung ihres Fensters zum
Client sind noch offen. Die separate Bildschirmfreigabe hat ihre eigene
Anleitung. [Bildschirm-Support](screen-support.md)
