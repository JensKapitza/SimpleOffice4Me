# Freigegebene Remote-Anwendungen ansehen

Unter **Werkzeuge & Dienste → Remote-Anwendungen** sehen angemeldete Benutzer
die aktiven Freigaben für ihr eigenes Konto. Die Seite zeigt Namen,
Beschreibungen und gekennzeichnete Favoriten. Wenn die Liste leer ist, kann
ein Administrator eine Anwendung dem Konto zuweisen.

Administratoren verwalten den Katalog weiterhin unter **System → Fernzugriff**.
Dort wählen sie beim Veröffentlichen einer lokal installierten Anwendung die
berechtigten Benutzer aus. Anwendungen ohne Benutzerzuordnung bleiben in der
Verwaltung sichtbar. Änderungen an Freigaben werden beim nächsten Laden der
Benutzeransicht berücksichtigt.

Der Status oberhalb der Liste gibt an, ob der Windows-Host unterstützt wird
und der Begleitagent eingerichtet, aktiv, inaktiv oder im Beenden begriffen
ist. Wenn die Statusabfrage fehlschlägt, bleiben die zugewiesenen Anwendungen
sichtbar. Für den Status zählt die letzte gültige Meldung des Begleitagenten
innerhalb der vergangenen 15 Sekunden. Start und Fensterübertragung sind
weitere Ausbaustufen.
